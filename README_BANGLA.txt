Earnora প্ল্যাটফর্মটি লোকালি (নিজের কম্পিউটারে) চালানোর সহজ নিয়ম:

যেহেতু এটি একটি প্রফেশনাল ফুল-স্ট্যাক ওয়েবসাইট (যেখানে ইউজার লগিন, ডেটাবেস এবং অ্যাডমিন প্যানেল আছে), তাই এটি সাধারণ HTML ফাইলের মতো ডাবল-ক্লিক করে চলবে না। এটি চালাতে নিচের ২ টি সহজ ধাপ অনুসরণ করুন:

ধাপ ১: Node.js ইন্সটল করুন (যদি আগে থেকে না থাকে)
- https://nodejs.org/ ওয়েবসাইটে যান।
- সেখান থেকে LTS (Long Term Support) ভার্সনটি ডাউনলোড করে ইন্সটল করে নিন।

ধাপ ২: ওয়েবসাইটটি চালু করুন
- আপনি যদি Windows কম্পিউটার ব্যবহার করেন, তবে ফোল্ডারের ভেতরে থাকা "run-windows.bat" ফাইলটিতে ডাবল-ক্লিক করুন।
- একটি কালো স্ক্রিন (Terminal) আসবে এবং কিছুক্ষণের মধ্যেই লেখা আসবে "Server running at http://0.0.0.0:3000"।
- এরপর আপনার ব্রাউজারে (Chrome/Edge) গিয়ে লিখুন: http://localhost:3000
- ব্যাস! আপনার সাইট রেডি।

বিঃদ্রঃ লাইভ করার জন্য (যাতে সবাই ইন্টারনেট থেকে ভিজিট করতে পারে), আপনাকে এই প্রজেক্টটি কোনো Node.js হোস্টিং (যেমন: Render.com, Vercel বা VPS) এ আপলোড করতে হবে। অথবা AI Studio এর "Share" বাটনে ক্লিক করে সরাসরি রেডিমেড লিংক ব্যবহার করতে পারেন।
